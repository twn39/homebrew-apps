# Homebrew Apps

Personal Homebrew Tap for macOS applications.

## Installation

Add this tap and install any application:

```bash
brew install --cask twn39/apps/<app-name>
```

Or tap first:

```bash
brew tap twn39/apps
brew install --cask <app-name>
```

## Available Applications

| App | Description | Install Command |
| :--- | :--- | :--- |
